I completed all the work from Chapters 14, 15, and 17.

When you open the project, select the "Terrain" scene in Assets/Scenes to view the completed work.

The Assets/Imports folder contains the music and sound effects I used, which are the same as those used in the textbook. In the Hierarchy, the Music and rain GameObjects contain the audio sources. The audio mixer is located at Assets/Main Mixer.mixer.

The UI assets are in Assets/Imports, and the UI elements are set up under the Canvas GameObject in the Hierarchy. The scripts for the player health bar, base health bar, and pause functionality are in Assets/Scripts.

The animations I created, including the intro animation, are in Assets/Animations. I also used animations from the SciFiWarriorPBRHPPolyart package in Assets/Imports. Following the textbook, I set up a new character model and changed the camera to a third-person view using Cinemachine. I also gave enemies a model with animation as well.
